# Design records

Phase 0 artefacts for the backend and GUI overhaul. These are review
and implementation inputs, not user documentation.

| File | Purpose |
|---|---|
| `baseline.md` | Captured pre-change test, build and budget results |
| `panel-registry.md` | Frozen no-loss panel checklist and capability map |
| `panel-inventory.json` | Machine-readable inventory for the Phase 2 test |
| `workspaces.md` | Workspace layouts, persistence, migration, detach, a11y |
| `shell.md` | Menubar, status cluster, workspace selector, bounds |
| `primitives.md` | UI primitive contracts and accessibility rules |
| `../armory-contract.md` | Locked armory source and repository contract |
| `../build-contract.md` | Shared build descriptor, field errors and validation rules |
| `../gui-cli-parity.md` | CLI/GUI parity matrix and manifest contract |

Related long-lived docs: `../gui-parity.md` (cutover history),
`../../DESIGN.md` (visual specification).
